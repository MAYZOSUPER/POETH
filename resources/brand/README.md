# Бренд POETH

Знак — «ромб обмена»: две встречные стрелки-шеврона и звезда в центре. Сгенерирован как вектор в Scenario
(модель Recraft V4.1 SVG, ассет `asset_3Te3MJbv6JSngyaSuyf3R5pA`), затем очищен: убран фон, обрезаны поля.
Надпись POETH собрана из контуров шрифта Cormorant SC Bold (OFL). Разделитель — Scenario, `asset_5o3omDqQVYEPFNX25Dq6ZDm6`.
Вся графика оригинальная: без логотипов, иконок и арта Grinding Gear Games.

Файлы раздаются протоколом `poeth://brand/<файл>` (см. `BrandImg`).

| Файл | Что | Где |
|---|---|---|
| `app_icon.png` | знак с тёмным контуром, 256 px, прозрачный | шапка компаньона (`Toolbar`), запасная иконка трея |
| `tray.png`, `tray@1.25x.png`, `tray@1.5x.png`, `tray@2x.png` | иконка трея 16/20/24/32 px, каждый размер отрисован отдельно | трей: Electron сам берёт вариант по масштабу экрана |
| `app_icon_tile.png`, `@2x` | плитка иконки приложения 256/512 px | «О программе», установщик; та же плитка в `build/icon.ico` |
| `logo.png`, `logo@2x.png` | знак + POETH, 640/1280 px | экран входа, мастер, «О программе» |
| `divider.png` | разделитель 1200 px | пустые состояния, экраны входа (`.empty-divider-img`) |
| `mark.svg` | знак, золото `#C9A55C` | мастер-файл |
| `mark-mono.svg` | знак на `currentColor` | внутри интерфейса, берёт цвет текста |
| `mark-outlined.svg` | знак с тёмным контуром | светлые фоны, трей |
| `logo.svg`, `wordmark.svg`, `app_icon_tile.svg`, `divider.svg` | векторные мастер-файлы | для новых размеров |
| `icons/*.svg`, `icons-sprite.svg` | 50 линейных иконок действий 24×24, линия 1.8, `currentColor` | кнопки, меню, вкладки (класс `.ui-ico`) |
| `tray-default.png` | старая запасная иконка компаса | можно удалить, когда трей перейдёт на `tray.png` |

## Правила
- Минимальный размер знака 16 px, логотипа 20 px по высоте. Свободное поле вокруг знака — четверть его ширины.
- Цвета только из палитры: `#C9A55C`, `#E3C47F`, `#120F0C`. Не растягивать, не поворачивать, не перекрашивать в другие цвета.
- POETH не набирать другим шрифтом: только готовые контуры (`wordmark.svg`, `logo.*`) или текст `--font-display`.
- Новые размеры рендерить из SVG, а не масштабировать PNG.
- Иконки действий — свои, отрисованы вручную под 15 px; новые рисовать в той же манере (сетка 24, линия 1.8, скругления).
