**POETH v0.1.0**

## Что нового

- Первый выпуск для PoE 1: прайс-чек по Ctrl+D с «честной ценой», трейд-окно с избранным, live search, regex-строки, менеджер сделок, команды чата по клавишам.
- PoE 2: трекер кампании и прайс-чек — как в Exile Companion.

**Как установить:** скачайте `POETH-Setup-0.1.0.exe` ниже и запустите — [пошагово](https://github.com/MAYZOSUPER/POETH#как-установить). Без установки — `POETH-Portable-0.1.0.exe` (обновляется вручную).

## What's new

- First release for PoE 1: Ctrl+D price check with a “fair price”, trade window with favorites, live search, regex strings, trade manager, chat commands on hotkeys.
- PoE 2: campaign tracker and price check — as in Exile Companion.

**How to install:** download `POETH-Setup-0.1.0.exe` below and run it — [step by step](https://github.com/MAYZOSUPER/POETH/blob/main/README.en.md#how-to-install). No install — `POETH-Portable-0.1.0.exe` (updated manually).
