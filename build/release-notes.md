**POETH v0.1.0-rc.11**

## Что нового

- Это демо-версия для знакомства: могут быть ошибки. Полноценный релиз v0.1.0 — 11 ноября, установленная версия обновится до него сама.
- PoE 1: цена предмета по Ctrl+D с подсказкой, что с ним делать, трейд-окно с избранным, live search, сделки, команды чата по клавишам.
- «Обмен» валюты у Фаустуса (таблица «Рыночный курс» с экрана по Alt+D — бета), «Богатство» и трекер карт, regex для карт и торговца, гид прокачки.
- Русский и английский клиент игры: названия предметов, зон и квестов — на языке игры.
- PoE 2: трекер кампании и цена предмета.

**Как установить:** скачайте `POETH-Setup-0.1.0-rc.11.exe` ниже и запустите — [пошагово](https://github.com/MAYZOSUPER/POETH#как-установить). Без установки — `POETH-Portable-0.1.0-rc.11.exe`: она сама не обновляется, релиз 11 ноября скачайте вручную. Как пользоваться — [гайд по функциям](https://mayzosuper.github.io/POETH/guide/).

## What's new

- This is a demo version to try POETH out: expect some bugs. The full v0.1.0 release is on November 11, and the installed version updates to it by itself.
- PoE 1: Ctrl+D item price with a hint on what to do with the item, trade window with favorites, live search, trades, chat commands on hotkeys.
- Currency Exchange at Faustus (“Market Ratio” table from the screen with Alt+D — beta), Wealth and map tracker, regex for maps and vendors, leveling guide.
- English and Russian game client: item, zone and quest names follow the game's language.
- PoE 2: campaign tracker and item price.

**How to install:** download `POETH-Setup-0.1.0-rc.11.exe` below and run it — [step by step](https://github.com/MAYZOSUPER/POETH/blob/main/README.en.md#how-to-install). No install — `POETH-Portable-0.1.0-rc.11.exe`: it does not update itself, download the November 11 release manually. How to use it — [feature guide](https://mayzosuper.github.io/POETH/guide/?lang=en).
