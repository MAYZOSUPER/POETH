**POETH v0.1.0**

## Что нового

- Полноценный релиз к лиге Covens of Umbra: на новую лигу POETH переключится сам, новые свойства предметов подтягивает с сайта трейда.
- Полные данные 3.30 (моды, regex-карты) приедут обновлением без переустановки в первые дни лиги — после тоста «Данные обновлены» перезапустите POETH.
- Всё из демо rc.13–rc.15 на месте: прайс-чек Ctrl+D, трейд-окно, live search, сделки, «Обмен», «Богатство», regex, гид прокачки.
- Режим PoE 2: трекер кампании, цена предмета, live search, сделки, regex, «Слухи журнала», «Билд», «Богатство».
- PoE 2 проверен без игры; данные под PoE 2 1.0 (11 декабря) обновим. Как пользоваться — гайд, раздел PoE 2.

**Как установить:** скачайте `POETH-Setup-0.1.0.exe` ниже и запустите — [пошагово](https://github.com/MAYZOSUPER/POETH#как-установить). Без установки — `POETH-Portable-0.1.0.exe`: она сама не обновляется, новые версии скачивайте вручную. Как пользоваться — [гайд по функциям](https://mayzosuper.github.io/POETH/guide/).

## What's new

- The full release, ready for the Covens of Umbra league: POETH switches to the new league by itself and picks up new item mods from the trade site.
- Full 3.30 data (mods, map regex) arrives as an in-app data update in the league's first days — after the “Data updated” toast, restart POETH.
- Everything from the rc.13–rc.15 demos is here: the Ctrl+D price check, trade window, live search, deals, “Exchange”, “Wealth”, regex, the leveling guide.
- PoE 2 mode: the campaign tracker, item price, live search, deals, regex, “Logbook rumours”, “Build”, “Wealth”.
- PoE 2 is tested without the game; data will be updated for PoE 2 1.0 (December 11). How to use it — the guide, PoE 2 section.

**How to install:** download `POETH-Setup-0.1.0.exe` below and run it — [step by step](https://github.com/MAYZOSUPER/POETH/blob/main/README.en.md#how-to-install). No install — `POETH-Portable-0.1.0.exe`: it does not update itself, download new versions manually. How to use it — [feature guide](https://mayzosuper.github.io/POETH/guide/?lang=en).
