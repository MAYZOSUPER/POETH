**POETH v0.1.0-rc.12**

## Что нового

- Это демо-версия для знакомства: могут быть ошибки. Полноценный релиз v0.1.0 — 11 ноября, установленная версия обновится до него сама.
- Вкладка «Билд»: вставьте ссылку или код PoB — этапы прокачки, камни, предметы этапа с кнопкой «Трейд», дерево билда поверх игрового по Alt+P.
- Окно цены Ctrl+D: «Против надетого» — лучше или хуже надетой вещи (точный расчёт через Path of Building — бета), оценка timeless-самоцветов, ссылки на poedb, вики и poe.ninja.
- Трейд-окно: вкладки сайтов — poe.ninja, poedb, вики, Maxroll, poelab, Craft of Exile, PoE Scout.
- «Что фармить», «Обмен → Предметы» (уники дешевле рынка), regex «Предметы» для тайника.
- PoE 2: цена предмета с модами по Ctrl+D, как в PoE 1; вход в аккаунт общий — через сайт GGG.

**Как установить:** скачайте `POETH-Setup-0.1.0-rc.12.exe` ниже и запустите — [пошагово](https://github.com/MAYZOSUPER/POETH#как-установить). Без установки — `POETH-Portable-0.1.0-rc.12.exe`: она сама не обновляется, релиз 11 ноября скачайте вручную. Как пользоваться — [гайд по функциям](https://mayzosuper.github.io/POETH/guide/).

## What's new

- This is a demo version to try POETH out: expect some bugs. The full v0.1.0 release is on November 11, and the installed version updates to it by itself.
- Build tab: paste a PoB link or code — leveling stages, gems, stage items with a Trade button, the build's passive tree over the in-game one with Alt+P.
- Ctrl+D price window: “Versus equipped” — better or worse than what you wear (exact calculation via Path of Building — beta), timeless jewel evaluation, links to poedb, the wiki and poe.ninja.
- Trade window: site tabs — poe.ninja, poedb, wiki, Maxroll, poelab, Craft of Exile, PoE Scout.
- “What to farm”, “Exchange → Items” (uniques below market), “Items” regex for the stash.
- PoE 2: item price with mods on Ctrl+D, like in PoE 1; one shared account login via GGG's website.

**How to install:** download `POETH-Setup-0.1.0-rc.12.exe` below and run it — [step by step](https://github.com/MAYZOSUPER/POETH/blob/main/README.en.md#how-to-install). No install — `POETH-Portable-0.1.0-rc.12.exe`: it does not update itself, download the November 11 release manually. How to use it — [feature guide](https://mayzosuper.github.io/POETH/guide/?lang=en).
