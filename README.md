# PoE2 Quest Overlay

Прозрачный оверлей-трекер кампании **Path of Exile 2**: чек-лист квестов по актам
(обязательные / необязательные + награды), картинки лейаутов зон, подсказки по
камням умений, несколько профилей персонажей. Работает поверх игры.

> Неофициальный фанатский инструмент. Не связан с Grinding Gear Games. См. [NOTICE.md](NOTICE.md).

## Возможности (текущая версия — MVP)

- ✅ Квесты по актам (1–4), разделение обязательные / необязательные, бейджи наград
  (очки умений, дух, сопротивления, жизнь/мана, камни и т.д.)
- ✅ Ручные галочки выполнения, сохраняются между запусками
- ✅ Несколько профилей персонажей (создание / переключение / переименование / удаление)
- ✅ Лейауты зон Act 1 (картинки Exile-UI, MIT) — ленивая загрузка + кэш
- ✅ Подсказки по камням умений (ранние умения по классам)
- ✅ Оверлей: прозрачное окно поверх игры, клик-сквозь, прозрачность, блокировка, хоткеи

## Запуск (разработка)

```bash
npm install
npm run dev      # запуск с hot-reload
```

Если `npm install` не докачал бинарь Electron (ошибка `Electron uninstall` при
запуске), запусти установку бинаря вручную:

```bash
node node_modules/electron/install.js
```

> ⚠️ Игра должна работать в режиме **«Окно»** или **«Окно без рамки»**.
> В эксклюзивном полноэкранном режиме оверлей Windows не отображается.

## Горячие клавиши

| Действие | Клавиши |
|---|---|
| Показать / скрыть оверлей | `Ctrl+Shift+O` |
| Блокировка кликов (всё уходит в игру) | `Ctrl+Shift+L` |
| Предыдущая / следующая зона | `Ctrl+Shift+[` / `]` |

## Сборка инсталлятора

```bash
npm run build       # сборка main/preload/renderer
npm run package     # NSIS-инсталлятор в dist-release/
```

> Для публичного релиза без предупреждений SmartScreen нужна подпись кода
> (OV/EV-сертификат). До этого Windows покажет «Подробнее → Выполнить в любом случае».

## Данные

Датасет генерируется скриптом из источников с открытой лицензией —
см. [tools/dataset-build/README.md](tools/dataset-build/README.md).

```bash
npm run build:data     # пересобрать resources/data из источников
npm run validate:data  # проверить датасет
```

Прогресс и настройки хранятся в `%APPDATA%/PoE2 Quest Overlay/` (атомарная запись).

## Структура

```
src/main      — главный процесс (окно-оверлей, клик-сквозь, хоткеи, IPC, хранилища)
src/preload   — мост contextBridge (window.overlayApi)
src/renderer  — React-интерфейс (панели, состояние)
src/shared    — общие типы и IPC-контракт
resources/data — собранный read-only датасет
tools/dataset-build — пайплайн сборки датасета
```
