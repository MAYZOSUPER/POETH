# Советник «Что фармить» (S16)

Вкладка PoE 1 для новичков: карточки стратегий фарма с оценкой дохода по живым ценам, сложностью, тем, что
нужно билду, и пошаговой инструкцией, плюс связь с трекером карт («Мой результат» против оценки). Только
подсказки: никаких действий в игре, сессию фарма игрок начинает сам кнопкой.

**Статус:** каркас + 3 демо-стратегии «черновик (3.29)». Стратегии под 3.30 заполняем после патчноутов
(атлас изменится) — по разделу «Как добавить стратегию» ниже.

## Включение
- В релизе v0.1.0 вкладка **скрыта**: `GameDef.features.advisor = false` (`src/shared/games.ts`) в обеих играх.
- В разработке — переменная окружения **`POETH_ADVISOR=1`** (`src/shared/advisor/flag.ts`): её читают main
  (домен считает только при флаге) и preload (`overlayApi.advisor.devFlag` → `tabs.ts` показывает вкладку).
  Работает только в PoE 1 (данные стратегий есть только для неё).
  ```bash
  POETH_ADVISOR=1 npm run dev
  ```
  В PowerShell: `$env:POETH_ADVISOR = '1'; npm run dev`.
- Включить для игроков: `advisor: true` у `poe1` в `games.ts` (и поправить `tests/games.test.ts`,
  `tests/advisor/flag.test.ts`). До этого — макет у дизайнера (своего макета у вкладки пока нет, вёрстка по
  дизайн-системе в духе «Обмена»).

## Откуда цены и время
- **Цены** — тот же индекс, что у снимков тайника учёта богатства (`getPriceIndex(league)` в
  `src/main/ipc/wealth.ts`): фид обмена GGG (VWAP 6/24/48 ч), затем poe.watch, если он включён во вкладке
  «Богатство». Своего источника у советника нет.
- **Время карты** (минут с заходом в убежище = время сессии без пауз ÷ карт): 1) ваши сессии фарма с меткой этой
  стратегии; 2) все ваши сессии; 3) `minutesPerMap` стратегии. Источник берётся, если в нём ≥ 3 карт и время > 0.
- **«Мой результат»** — сессии фарма с меткой стратегии (`FarmSession.strategy`, ставится кнопкой «Начать
  сессию фарма с этой стратегией» или «Отметить идущую сессию»): сессии, карты, время, доход в час (только по
  сессиям, где учёт тайника посчитал прибыль), сравнение с оценкой (±25% — «около оценки»).

## Расчёт (`src/shared/advisor/estimate.ts`)
- Вход за карту = Σ цена × количество покупных предметов; свой предмет (`own: true`, карта с прошлых карт) — 0.
- Добыча за карту = Σ цена × количество по строкам **с ценой**.
- **Нет цены — `null`, не 0.** У покупного входа без цены нет ни стоимости, ни прибыли («нет цены» с перечнем в
  подсказке). У части добычи нет цены — доход и прибыль «не меньше» (`≥ ~X`): цены положительны, неизвестная
  добыча может только прибавить.
- Прибыль в час = прибыль за карту × 60 ÷ минут на карту; время 0 или неизвестно — дохода в час нет.
- Несколько кандидатов цены (варианты на poe.watch) — медиана с пометкой «мало сделок».
- **Уверенность** ●●● / ●●○ / ●○○: низкая — прибыль не посчитать или больше половины стоимости по ценам «мало
  сделок»; средняя — есть такие цены, добыча без цены или стратегия-черновик; иначе высокая. Причины — в подсказке.

## Формат `resources/data/poe1/advisor/strategies.json`
Файл едет через канал обновления данных (S12): `tools/data/publish-data.mjs` собирает всё из
`resources/data/poe1/**`, приложение берёт `userData/data/poe1/advisor/strategies.json` раньше встроенного.
В `data.meta.json` его нет (там только файлы APT, `npm run verify:data` их сверяет). Проверку формата делает
`parseAdvisorData` (`src/shared/advisor/data.ts`): битая стратегия или термин отбрасываются по одному (в UI —
«Пропущено стратегий с ошибками»), файл другой версии — не читается (берётся встроенный).

```jsonc
{
  "version": 1,                 // формат; новый формат — новая версия (старое приложение его не прочитает)
  "patch": "3.29",              // для какой версии игры — в баннере «Черновик 3.29»
  "updatedAt": "2026-10-28",    // YYYY-MM-DD
  "draft": true,                // черновик: баннер на вкладке, метка на карточках, уверенность не выше средней
  "defaults": { "minutesPerMap": 5 },
  "glossary": {                 // термины: ключ — латиница/цифры/дефис
    "scarab": { "term": { "ru": "Скарабей", "en": "Scarab" }, "tip": { "ru": "…", "en": "…" } }
  },
  "strategies": [
    {
      "id": "essence-basic",    // ^[a-z0-9][a-z0-9-]{0,47}$, уникальный; это метка у сессий фарма — НЕ переименовывать
      "name":    { "ru": "…", "en": "…" },
      "summary": { "ru": "…", "en": "…" },        // одна строка под названием
      "why":     { "ru": "…", "en": "…" },        // «почему это выгодно» простым языком
      "difficulty": 1,                            // 1 лёгкая, 2 средняя, 3 сложная
      "build": { "damage": 2, "survival": 1, "speed": 1, "note": { "ru": "…", "en": "…" } }, // 1 немного … 3 много
      "tags": ["essence", "maps"],                // механики (пока не показываются; для фильтров потом)
      "terms": ["essence", "scarab"],             // ключи glossary — чипы «Термины» с подсказками
      "minutesPerMap": 5,                         // необязательно, иначе defaults.minutesPerMap
      "inputs": [                                 // что вложить за карту (может быть пустым)
        { "item": { "kind": "map", "label": { "ru": "Карта T14–16", "en": "Map T14–16" } }, "qty": 1, "own": true,
          "note": { "ru": "своя", "en": "your own" } },
        { "item": { "kind": "stackable", "name": "Essence Scarab" }, "qty": 1 }
      ],
      "outputs": [                                // что получите за карту, хотя бы одна строка
        { "item": { "kind": "stackable", "name": "Deafening Essence of Greed" }, "qty": 0.3 },
        { "item": { "kind": "stackable", "label": { "ru": "Прочие сущности", "en": "Other essences" } }, "qty": 3 }
      ],
      "source": { "text": { "ru": "…", "en": "…" }, "date": "2026-10" },   // откуда количества (YYYY-MM[-DD])
      "atlas":    [{ "ru": "…", "en": "…" }],     // что взять на атласе
      "steps":    [{ "ru": "…", "en": "…" }],     // что делать, хотя бы один шаг
      "warnings": [{ "ru": "…", "en": "…" }],
      "draft": true,                              // необязательно, иначе как у файла
      "patch": "3.29"                             // необязательно, иначе как у файла
    }
  ]
}
```

Предмет (`item`):
| Поле | Что |
|---|---|
| `kind` | `stackable` (валюта, скарабеи, сущности, осколки, артефакты…), `card` (карта Таро), `map`, `unique`, `gem`; по умолчанию `stackable` |
| `name` | **английское** имя как в фиде обмена / poe.watch — по нему цена; русское имя берётся из данных APT |
| `label` | подпись вместо имени («Карта T14–16», «Прочие сущности») — у предмета без `name` цены нет |
| `tier` | ярус карты (`map`) |
| `level`, `quality` | уровень и качество камня (`gem`, по умолчанию 1 и 0, не осквернённый) |

`qty` — штук за карту, дробное = в среднем (0.3 — примерно раз в три карты). Тексты — обязательно оба языка,
до 600 символов.

## Как добавить стратегию (после патчноутов 3.30)
1. Выбрать механику, которая жива в новой лиге, и проверить её по патчноутам (атлас, скарабеи).
2. Имена предметов — **английские**, точно как на обмене: список имён фида —
   `resources/data/poe1/wealth/exchange-ids.json` (обновляется `tools/wealth/sync-exchange-ids.mjs` из RePoE),
   русское имя должно быть в `resources/data/poe1/ru/items.ndjson` (данные APT; после ресинка 3.30 — проверить).
3. Количества — **свои замеры** (трекер карт: несколько сессий с меткой стратегии, «Мой результат») или грубая
   оценка с честным `source`. Тексты/числа с чужих сайтов не копировать.
4. Для новичка: сложность честно, `build` — что именно нужно (урон / живучесть / скорость), шаги короткие, без
   жаргона; незнакомые слова — в `glossary` и `terms`. Предупреждения — про то, что убивает слабый билд.
5. `npm test` — `tests/advisor/data.test.ts` проверяет комплектный файл: без ошибок разбора, RU по-русски / EN без
   кириллицы, термины есть в словаре, имена есть на обмене (для `stackable`) и в русских данных APT.
6. Снять `draft` (у файла и стратегий) и поменять `patch`, когда числа сверены в новой лиге; опубликовать пакет
   данных (`docs/league-update.md`, `tools/data/publish-data.mjs`) — приложение подтянет без переустановки.
7. `id` существующих стратегий не менять: по нему считается «Мой результат» прошлых сессий.

## Идеи из обзора (только идеи, тексты и данные не брали)
- Wealthy Exile: у стратегии — прибыль и **вложения в час**, длительность замера, разбивка добычи; числа пишут
  игроки и они зависят от лиги, билда и удачи. У нас: вложения в час (эксперт), источник количеств с датой,
  разбивка «что получите» с ценами, свой результат по трекеру вместо чужого.
- «Farm of Exile» как отдельный сервис не нашёлся — сравнения нет.
- Чего у них нет и что важно новичку: что нужно билду, сложность, термины с подсказками, «почему выгодно»
  простым языком, честное «нет цены» вместо нуля.
