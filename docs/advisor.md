# Советник «Что фармить» (S16, S17)

Вкладка PoE 1 для новичков: карточки стратегий фарма с оценкой дохода по живым ценам, сложностью, тем, что
нужно билду, и пошаговой инструкцией, плюс связь с трекером карт («Мой результат» против оценки). Только
подсказки: никаких действий в игре, сессию фарма игрок начинает сам кнопкой.

**Статус:** каркас + 3 демо-стратегии «черновик (3.29)». Стратегии под 3.30 заполняем после патчноутов
(атлас изменится) — по разделу «Как добавить стратегию». S17 — стратегии игроков: редактор, код `POETH1:…` и
ссылка, импорт, каталог сообщества в приложении и на сайте — раздел «Стратегии игроков (S17)».

## Откуда цены и время
- **Цены** — тот же индекс, что у снимков тайника учёта богатства (`getPriceIndex(league)` в
  `src/main/ipc/wealth.ts`): фид обмена GGG (VWAP 6/24/48 ч), затем poe.watch, если он включён во вкладке
  «Богатство». Своего источника у советника нет. **В стратегии цен нет** — только количества.
- **Время карты** (минут с заходом в убежище = время сессии без пауз ÷ карт): 1) ваши сессии фарма с меткой этой
  стратегии; 2) все ваши сессии; 3) `minutesPerMap` стратегии. Источник берётся, если в нём ≥ 3 карт и время > 0.
- **«Мой результат»** — сессии фарма с меткой стратегии (`FarmSession.strategy`, ставится кнопкой «Начать
  сессию фарма с этой стратегией» или «Отметить идущую сессию»): сессии, карты, время, доход в час (только по
  сессиям, где учёт тайника посчитал прибыль), сравнение с оценкой (±25% — «около оценки»).

## Расчёт (`src/shared/advisor/estimate.ts`)
- Вход за карту = Σ цена × количество покупных предметов; свой предмет (`own: true`, карта с прошлых карт) — 0.
- Добыча за карту = Σ цена × количество по строкам **с ценой**.
- **Нет цены — `null`, не 0.** У покупного входа без цены нет ни стоимости, ни прибыли («нет цены» с перечнем в
  подсказке). У части добычи нет цены — доход и прибыль «не меньше» (`≥ ~X`): цены положительны, неизвестная
  добыча может только прибавить.
- Прибыль в час = прибыль за карту × 60 ÷ минут на карту; время 0 или неизвестно — дохода в час нет.
- Несколько кандидатов цены (варианты на poe.watch) — медиана с пометкой «мало сделок».
- **Уверенность** ●●● / ●●○ / ●○○: низкая — прибыль не посчитать или больше половины стоимости по ценам «мало
  сделок»; средняя — есть такие цены, добыча без цены или стратегия-черновик; иначе высокая. Причины — в подсказке.
- Сортировки: по доходу в час, сначала лёгкие, **дешёвый вход** (стоимость входа за карту).

## Формат `resources/data/poe1/advisor/strategies.json` (схема 1)
Файл едет через канал обновления данных (S12): `tools/data/publish-data.mjs` собирает всё из
`resources/data/poe1/**`, приложение берёт `userData/data/poe1/advisor/strategies.json` раньше встроенного.
В `data.meta.json` его нет (там только файлы APT, `npm run verify:data` их сверяет).
Разбор — `parseAdvisorData` (`src/shared/advisor/data.ts`), каждая стратегия — строгий `validateStrategy`
(`src/shared/advisor/validate.ts`): битая стратегия или термин отбрасываются по одному (в UI — «Пропущено
стратегий с ошибками»), файл другой схемы — не читается (берётся встроенный).

```jsonc
{
  "schema": 1,                  // версия схемы; новые поля = новая схема (валидатор строгий) + minApp пакета данных
  "patch": "3.29",              // версия игры данных: другая у стратегии — «может устареть»
  "updatedAt": "2026-10-28",
  "draft": true,                // черновик: баннер, метка на карточках, уверенность не выше средней
  "defaults": { "minutesPerMap": 5 },
  "glossary": {                 // термины: ключ — латиница/цифры/дефис
    "scarab": { "term": { "ru": "Скарабей", "en": "Scarab" }, "tip": { "ru": "…", "en": "…" } }
  },
  "strategies": [
    {
      "id": "essence-basic",    // ^[a-z0-9][a-z0-9-]{0,47}$, уникальный; метка у сессий фарма — НЕ переименовывать
      "name":    { "ru": "…", "en": "…" },        // тексты: хотя бы один язык, второй UI подставит с меткой
      "summary": { "ru": "…", "en": "…" },        //   «написано на английском»
      "why":     { "ru": "…", "en": "…" },        // «почему это выгодно» простым языком
      "difficulty": 1,                            // 1 лёгкая, 2 средняя, 3 сложная
      "build": { "damage": 2, "survival": 1, "speed": 1, "note": { "ru": "…" } }, // 1 немного … 3 много
      "tags": ["essence", "maps"],                // механики (для фильтров потом)
      "terms": ["essence", "scarab"],             // ключи glossary — чипы «Термины» с подсказками
      "minutesPerMap": 5,                         // 0.5…120; в файле можно не писать — defaults
      "inputs": [                                 // что вложить за карту (0…12 строк)
        { "item": { "kind": "map", "label": { "ru": "Карта T14–16", "en": "Map T14–16" } }, "qty": 1, "own": true },
        { "item": { "kind": "stackable", "ref": "Essence Scarab" }, "qty": 1 }
      ],
      "outputs": [                                // что получите за карту (1…20 строк)
        { "item": { "kind": "stackable", "ref": "Deafening Essence of Greed" }, "qty": 0.3 },
        { "item": { "kind": "stackable", "label": { "ru": "Прочие сущности", "en": "Other essences" } }, "qty": 3 }
      ],
      "source": {                                 // откуда стратегия
        "kind": "official",                       // official | community | imported | mine | wealthy
        "author": "POETH",                        // ник, до 40 символов; аккаунт и персонаж — нельзя
        "url": "https://…",                       // оригинал, только https (у wealthy — только wealthyexile.com)
        "date": "2026-10",                        // YYYY-MM[-DD]
        "note": { "ru": "грубая оценка…", "en": "rough estimate…" }   // откуда количества
      },
      "measured": { "maps": 40, "hours": 3.5, "perHour": 120, "date": "2026-10-20", "patch": "3.29" }, // замер автора
      "atlas":    [{ "ru": "…", "en": "…" }],     // что взять на атласе (до 8)
      "atlasTree": "https://www.pathofexile.com/fullscreen-atlas-skill-tree/…", // дерево атласа (S17, https)
      "steps":    [{ "ru": "…", "en": "…" }],     // что делать (1…12)
      "warnings": [{ "ru": "…", "en": "…" }],     // до 6
      "draft": true,                              // в файле можно не писать — как у файла
      "patch": "3.29",                            // в файле можно не писать — как у файла; у импорта обязателен
      "league": "Settlers"                        // необязательно
    }
  ]
}
```

Предмет (`item`):
| Поле | Что |
|---|---|
| `kind` | `stackable` (валюта, скарабеи, сущности, осколки, артефакты…), `card` (карта Таро), `map`, `unique`, `gem`; по умолчанию `stackable` |
| `ref` | **стабильный id**: английское имя = `refName` данных APT = имя в фиде обмена и poe.watch, одинаковое для RU и EN клиента. По нему цена, русское имя — из данных APT |
| `label` | подпись вместо имени («Карта T14–16», «Прочие сущности») — у предмета без `ref` цены нет |
| `tier` | ярус карты (`map`, 1–17) |
| `level`, `quality` | уровень и качество камня (`gem`, по умолчанию 1 и 0, не осквернённый) |

Правила валидатора (`validate.ts`, тесты — `tests/advisor/validate.test.ts`):
- неизвестные поля на любом уровне — ошибка (поле цены в строке тоже: цены всегда живые);
- только простой текст: без HTML-тегов, управляющих символов и символов смены направления текста;
- лимиты: название 60, кратко 200, «почему» 600, шаг 300, заметка 120, автор 40, ссылка 300 символов; вход ≤ 12,
  добыча 1…20, шагов 1…12, атлас ≤ 8, предупреждений ≤ 6, тегов ≤ 8, терминов ≤ 12; `qty` 0…10 000;
- `ref` — буквы любого алфавита, цифры и `' , . : - ( )`;
- `source.url` и `atlasTree` — только https без логина в адресе; у `wealthy` автор и ссылка обязательны (атрибуция);
  ссылка на дерево атласа с сайта не из allowlist внешних ссылок не открывается — копируется (домен виден);
- `source.kind`: `mine` (своя из редактора, S17) — допустим; в коде вид источника не доверяется (импорт — `imported`).

## Как добавить стратегию (после патчноутов 3.30)
1. Выбрать механику, которая жива в новой лиге, и проверить её по патчноутам (атлас, скарабеи).
2. `ref` — **английские** имена, точно как на обмене: список имён фида —
   `resources/data/poe1/wealth/exchange-ids.json` (обновляется `tools/wealth/sync-exchange-ids.mjs` из RePoE),
   русское имя должно быть в `resources/data/poe1/ru/items.ndjson` (данные APT; после ресинка 3.30 — проверить).
3. Количества — **свои замеры** (трекер карт: несколько сессий с меткой стратегии, «Мой результат» → `measured`)
   или грубая оценка с честным `source.note`. Тексты/числа с чужих сайтов не копировать.
4. Для новичка: сложность честно, `build` — что именно нужно (урон / живучесть / скорость), шаги короткие, без
   жаргона; незнакомые слова — в `glossary` и `terms`. Предупреждения — про то, что убивает слабый билд.
5. `npm test` — `tests/advisor/data.test.ts` проверяет комплектный файл: строгий валидатор без ошибок, наши тексты
   на обоих языках (RU по-русски, EN без кириллицы), термины есть в словаре, `ref` есть на обмене (для
   `stackable`) и в русских данных APT.
6. Снять `draft` и поменять `patch` (у файла и стратегий), когда числа сверены в новой лиге; опубликовать пакет
   данных (`docs/league-update.md`, `tools/data/publish-data.mjs`) — приложение подтянет без переустановки.
7. `id` существующих стратегий не менять: по нему считается «Мой результат» прошлых сессий.

## Стратегии игроков (S17): код, импорт, «Поделиться», каталог
Своего сервера нет: стратегия живёт в коде и ссылке, каталог — файлы в репозитории, сайт — статичный.

### Код `POETH1:` (`src/shared/advisor/codec.ts`)
- `POETH1:` + base64url(deflate(JSON)), как в PoB. Внутри — `{ "schema": 1, "strategy": {…} }`: цифра в префиксе —
  версия формата кода, `schema` — версия модели. Новее любой из них — «код из более новой версии POETH».
- Цен в коде нет (только количества), аккаунта, персонажа, тайника и истории сессий — тоже (их нет в модели).
  У своей стратегии «Поделиться» добавляет ник (`source.author`), если игрок его указал.
- Код — **недоверенные данные**: длина кода ≤ 32 000 символов (меньше лимита командной строки Windows для ссылки
  протокола), JSON после распаковки ≤ 64 КБ — распаковка обрывается на пределе (zip-бомба: zlib `maxOutputLength`
  в main, счёт байт потока `DecompressionStream` на сайте); дальше — всегда строгий `validateStrategy` без значений
  по умолчанию. Ошибки: «не код POETH», «код обрезан или повреждён», «новая версия», «слишком большой», «в коде
  ошибки» (с причиной валидатора в экспертном режиме).
- Сжатие подставляется снаружи: `codecNode.ts` (main, тесты, инструменты), `codecBrowser.ts` (сайт). Тест проверяет,
  что коды из zlib и `CompressionStream` взаимно читаются.
- **Отпечаток** (`strategyFingerprint`) — содержание стратегии без источника (вид, автор, дата) и пометки черновика:
  по нему «уже есть» в импорте и «В каталоге POETH» на сайте.

### Свои стратегии (`src/shared/advisor/library.ts`, main — `src/main/ipc/advisor.ts`)
- Файл `userData/advisor/my-strategies.json` (атомарная запись `writeJsonAtomic`, `.bak`): `{ schema: 1, nick,
  items: [{ strategy, addedAt }], draft }`. Каждая запись при чтении проходит валидатор; битые отбрасываются по одной.
- Источник своих: `mine` — создана в редакторе (вид и дату ставит main при сохранении), `imported` — добавлена по
  коду (вид из кода не доверяется: всегда `imported`; автор, ссылка и дата оригинала сохраняются — атрибуция).
- **Импорт** — только по кнопке: код → main раскрывает и проверяет → предпросмотр с оценкой по живым ценам и
  замечаниями (нет цены у предмета, текст на одном языке, ссылка на сторонний сайт, другая версия игры) →
  «Добавить». «Уже есть»: точно такая (по отпечатку, где угодно) — «Открыть её»; своя с тем же `id`, но другая —
  «Заменить мою» (`id` тот же — «Мой результат» сохраняется) или «Добавить копией» (`id-2`…); наша или из каталога
  с тем же `id` — только копией. Своих — не больше 200.
- **Редактор** (`src/shared/advisor/draft.ts` — черновик ↔ стратегия, ошибки по шагам): шесть шагов; «что
  получаешь из моих сессий фарма» берёт только **замер** (`measured`: карты, часы, доход в час) и время карты —
  разбивки по предметам у трекера нет, строки добычи игрок пишет сам (по ним другие видят доход по своим ценам).
  Черновик сохраняется сам (тот же файл, ≤ 128 КБ). «Копия» нашей или из каталога — новая своя без чужого замера.
- Поиск предмета (`src/shared/advisor/items.ts`) — по русскому или английскому имени: данные APT + имена фида
  обмена; в стратегию уходит `ref` — английское имя; предметы обмена — выше камней и уников.

### «Поделиться» и каталог
- Ссылка — `https://mayzosuper.github.io/POETH/strategies/view#<код>` (код после `#`: браузер не отправляет эту
  часть на сервер). Адреса — `src/shared/links.ts` (`STRATEGY_VIEW_URL`, `STRATEGY_ISSUE_URL`), в общий
  allowlist renderer `github.com` и сайт не добавлены.
- «Отправить в каталог» — только у своей: main открывает форму `.github/ISSUE_TEMPLATE/strategy.yml`
  (`issues/new?template=strategy.yml&title=…&code=…`) отдельной функцией с точным адресом; адрес длиннее 7 500
  символов — форма без кода, код кладётся в буфер.
- **Лид добавляет одобренную**: `node tools/advisor/add-strategy.mjs <код или ссылка> --issue <номер>` — тот же
  валидатор (src/shared/advisor через esbuild), файл `resources/data/poe1/advisor/community/<id>.json`
  (`{ schema: 1, checked, issue?, strategy }`, `source.kind = community`), пересборка файлов сайта. `id` нашей
  стратегии занять нельзя (`--id` — другой), повтор — только `--replace`. Дальше: `npm test`, коммит, пакет данных
  (`tools/data/publish-data.mjs`) — игроки получат стратегию без переустановки; сайт обновится после push в main.
- Приложение читает каталог из встроенных данных и из обновлённых (`userData/data`), объединяя по имени файла:
  пакет данных кладёт только изменённые файлы. Убрать стратегию из каталога у старых версий нельзя (только заменить
  файл) — до выпуска новой версии приложения.
- `npm test` проверяет каждый файл каталога (`tests/advisor/community.test.ts`): схема, `community`, имя файла = `id`,
  строгий валидатор, `id` не совпадает с нашими, `stackable` есть на обмене. Рейтингов и комментариев нет (нужен сервер).

### Сайт (`site/strategies/`)
- `index.html` — каталог (наши и сообщества) с фильтрами; `view.html` — просмотр по ссылке: код раскрывается в
  браузере, совпадение с каталогом — «В каталоге POETH», иначе «Не проверена». Кнопки «Открыть в POETH»,
  «Скопировать код», «Скачать POETH»; «живые цены — в приложении».
- Тот же код, что в приложении: `strategy-core.js` — бандл `src/shared/advisor/site.ts` (формат, валидатор, расчёт),
  `catalog.json` (стратегии с готовыми кодами), `names-ru.json` (русские имена предметов) собирает
  `node tools/advisor/build-site.mjs`; `--check` и `tests/advisor/site.test.ts` ловят устаревшие файлы. Сборки на
  GitHub Pages нет — `pages.yml` не менялся.
- Безопасность: всё из кода — только через `textContent`/`setAttribute` (тест запрещает `innerHTML`, `eval` и т. п.),
  строгая CSP (`default-src 'none'`, только свои скрипты и стили, без встроенных), ссылки из стратегии — только
  https, в новой вкладке без referrer. Счётчиков нет.
- Доход на сайте: если рядом лежит снимок цен `prices.json` (`{ label: {ru, en}, items: PriceEntry[] }`), каталог
  отмечает его и сайт считает доход тем же расчётом; нет — показывается замер автора или «в приложении», фильтр
  бюджета скрыт. Инструмента снимка пока нет.
- Ссылки «Стратегии» в меню главной страницы нет — включим вместе с вкладкой после контента 3.30.

### «Открыть в POETH» — протокол `poeth-strategy://`
- Сайт ставит `poeth-strategy://import#<код>`. Установленная версия с включённым советником регистрирует схему
  `app.setAsDefaultProtocolClient` (`registerStrategyProtocol`); portable и разработка — нет (portable
  распаковывается во временную папку, путь меняется): там только «Скопировать код». `protocols` в
  `electron-builder.yml` — для macOS/Linux и как документация: NSIS electron-builder протоколы не регистрирует.
- Из аргументов запуска (первый запуск и `second-instance`) берётся **только** `poeth-strategy://import#<код>`
  (`deepLinkFromArgv`, `src/shared/advisor/share.ts`); любые другие аргументы и пути игнорируются. Код не
  раскрывается в main при запуске и ничего не добавляется: окно переключается на «Что фармить» и открывает
  «Импорт» с кодом — предпросмотр и «Добавить» по кнопке. Советник выключен — ссылка игнорируется.
- **Почему отдельная схема, а не `poeth://`.** `poeth://` — внутренняя привилегированная схема Chromium для окон
  приложения (`standard`, `secure`, `corsEnabled`, отдаёт файлы данных и иконки из `resources` и `userData`).
  Регистрация её в ОС дала бы любой веб-странице способ запускать POETH с адресами этого пространства
  (`poeth://data/…`, `poeth://brand/…`) и смешала бы два разных источника доверия в одном обработчике. Отдельная
  схема узкая (один путь `import`, только код), её разбор — чистая функция с тестами, а внутренняя `poeth://` из ОС
  по-прежнему не открывается. Минус — ключ реестра `HKCU\Software\Classes\poeth-strategy` остаётся после удаления
  программы (NSIS его не знает); убрать — строкой в `build/installer.nsh` (решение лида).

## Wealthy Exile: импорт стратегий (исследование 28.10.2026)
Пользователь предложил брать стратегии игроков с Wealthy Exile (WE): там советы с прибылью и вложениями в час.
Что выяснилось:
- **Открытого формата нет.** На странице стратегии (`/strategies/<id>/<slug>`) — автор, даты, сложность, теги,
  длительность, описание текстом, таблицы «вложения в час / доход в час» (имя, количество, цена). Кнопок экспорта,
  «поделиться», JSON или публичного API нет; список — `/strategies/public` (без экспорта). Получить стратегию можно
  только разбором HTML страницы — это скрейпинг, его не делаем.
- **Условий использования нет.** На сайте нет ToS/лицензии; политика конфиденциальности не говорит о правах на
  стратегии и их копировании; связь — только Discord сайта. Стратегии пишут игроки — права у авторов, разрешения
  на перенос нет. `robots.txt` закрывает только `/trade`, `/login`, `/logout`, `/profile` — это не разрешение
  копировать контент.
- **Итог:** импорт из WE сейчас не делаем — ни каталогом, ни ссылкой. Модель к нему готова:
  `source: { kind: 'wealthy', author, url }` с обязательной атрибуцией, ссылка — только на wealthyexile.com.

Варианты (решает пользователь):
1. **Ссылка-кнопка «Открыть на Wealthy Exile»** в карточке — уже работает для любой стратегии с `source.url`,
   если хост в allowlist внешних ссылок. `wealthyexile.com` в `EXTERNAL_HOSTS` (`src/shared/links.ts`,
   заморожен) нет — пока вместо кнопки «Скопировать ссылку на оригинал». Добавить хост — решение лида.
2. **Ручной ввод в нашем формате** (редактор S17): игрок сам переносит понравившуюся стратегию своими словами,
   со ссылкой на оригинал и автором; числа — свои замеры (`measured`).
3. **Письмо автору WE** (через Discord сайта) с просьбой о разрешении или об открытом экспорте/API для стратегий.
   С разрешением — импорт ссылкой или кодом через их формат, `source.kind = 'wealthy'`, атрибуция автора.

Идеи из обзора (без текстов и данных WE): у стратегии — прибыль и **вложения в час**, длительность замера,
разбивка добычи, пометка «сделано для прошлой лиги». У нас: вложения в час (эксперт), сортировка «дешёвый вход»,
`measured` с картами и часами, «может устареть» по версии игры, свой результат по трекеру.
«Farm of Exile» как отдельный сервис не нашёлся — сравнения нет.
