# «Справочник»: статьи как данные (S55)

Вкладка «Справочник» (рельс → «Помощь», иконка `book`, только PoE 1) показывает короткие статьи на RU и EN. Статья —
JSON в `resources/data/poe1/guide/`, а не код: её можно поправить или добавить **без переустановки** — каналом данных
(S12, `docs/league-update.md`). Игрок получит новую версию после перезапуска POETH (тост «Данные обновлены…»).

| Файл | Что |
|---|---|
| `resources/data/poe1/guide/index.json` | `{ "schema": 1, "articles": ["league-start", "glossary-basics"] }` — какие статьи и в каком порядке |
| `resources/data/poe1/guide/<id>.json` | статья; имя файла = её `id` |
| `src/shared/guide/article.ts` | схема, строгий валидатор, разметка `**…**` / `` `…` `` |
| `src/shared/guide/library.ts` | загрузка (битая статья не ломает остальные), поиск, «новое / обновлено», `guideOn(game)` |
| `src/renderer/src/panels/guide/` | вкладка: список, статья, блоки, переходы (`links.ts`), стили |
| `src/renderer/src/store/useGuideStore.ts` | чтение `poeth://data/poe1/guide/<файл>`, прочитанное — `localStorage` `poeth.guide.seen` |
| `tests/guide/` | валидатор, загрузка из встроенных данных и `userData/data`, поиск, переходы |

## Как добавить статью
1. Написать `resources/data/poe1/guide/<id>.json` по схеме ниже (`id` — латиница, цифры, дефис, 2–40 символов).
2. Вписать `id` в `index.json` на нужное место.
3. `npx vitest run tests/guide` — тест проверяет **все** файлы папки и что `index.json` перечисляет ровно их. Workflow
   «Data» гоняет `npm test` перед публикацией, поэтому статья, не прошедшая проверку, игрокам не уйдёт.
4. Посмотреть в приложении (RU и EN, простой и экспертный режим, окно 560 и 820 px).
5. После слияния в main — выпустить пакетом данных (Actions → «Data», `docs/league-update.md`).

Правка существующей статьи: **`rev` + 1** (иначе у игроков не будет отметки «Обновлено»), `updated` — дата правки,
у изменённых разделов — `"rev": <новая ревизия>` (у раздела появится «Обновлено», если игрок читал прошлую версию).

## Схема 1

```jsonc
{
  "schema": 1,                       // версия схемы; новее, чем знает приложение, — «обновите POETH», статья скрыта
  "id": "league-start",
  "rev": 1,                          // 1…9999, растёт при каждом изменении текста
  "updated": "2026-10-30",           // ГГГГ-ММ-ДД
  "patch": ["3.29", "3.30"],         // «Для 3.29 / 3.30», 1–4 версии вида 3.30
  "title":   { "ru": "…", "en": "…" },   // до 80, без разметки
  "summary": { "ru": "…", "en": "…" },   // до 240, в карточке списка
  "sections": [                      // 1–16
    {
      "id": "day-1",                 // уникален в статье; по нему переход из поиска и ссылки
      "title": { "ru": "…", "en": "…" }, // до 80, без разметки; ищется поиском (оба языка)
      "rev": 2,                      // необязательно: ревизия, в которой раздел менялся (≤ rev статьи)
      "expert": true,                // необязательно: в простом режиме — под кнопкой «Показать разделы для опытных»
      "blocks": [ /* 1–24 блока */ ]
    }
  ]
}
```

Блоки (у любого, кроме `pending`, можно `"expert": true` — в простом режиме скрыт):

| `kind` | Поля | Как выглядит |
|---|---|---|
| `text` | `text` (до 900) | абзац |
| `list` | `items` (1–16, по 400), `ordered` | список; `ordered: true` — нумерованный |
| `note` | `tone`: `tip` / `warn` / `bad`, `text` | баннер: подсказка (синий), предупреждение, опасно (красный) |
| `link` | `site`, `url`, `label` (до 80), `text` | кнопка ↗ и пояснение. `site` — сайт реестра трейд-окна (`ninja`, `poedb`, `wiki`, `maxroll`, `mobalytics`, `poelab`, `craft`, `scout`; открывается во вкладке трейд-окна, без `url` — главная) или `ggg` (pathofexile.com, в браузере, `url` обязателен). `url` — строка или `{ "ru": …, "en": … }`, только https и хост этого сайта |
| `app` | `to`, `label`, `text` | кнопка перехода в POETH. `to`: вкладка (`priceCheck`, `live`, `deals`, `flip`, `advisor`, `wealth`, `regex`, `campaign`, `build`), страница Regex (`regex/maps`, `regex/vendor`, `regex/items`, `regex/library`), другая статья (`guide/<id>`), `settings`. Вкладки нет в игре или версии (скрыта флагом) — блок не показывается |
| `terms` | `items`: `{ term: {ru, en} (до 60), def: {ru, en} (до 400) }`, 1–40 | словарь: термин на обоих языках и объяснение |
| `pending` | `text` | пунктирная рамка с меткой «Скоро» — раздел-каркас («появится после патчноутов») |

**Текст:** простой, без HTML, без переводов строки и служебных символов; абзацы — отдельные блоки `text`. Разметка
только `**жирный**` и `` `клавиша` `` (`Ctrl+D` рисуется клавишами); пары закрываются, вложенности нет. В заголовках,
подписях кнопок и терминах разметки нет. RU и EN обязательны оба. Файл — до 96 КБ.

Неизвестные поля и блоки — статья не загрузится (в списке «Не загрузилось статей: N», в консоли — причина). Нужен
новый блок — новая схема (`schema: 2`) и новая версия приложения; в пакете данных — `minApp`.

## Как писать
- **Своими словами.** Тексты вики, гайдов и сайтов не копируем, даже в переводе. Ссылку на источник можно дать блоком `link`.
- **Только проверенные факты.** Названия предметов в RU — как в клиенте: сверять с `resources/data/poe1/ru/items.ndjson`
  (`"refName":"Jeweller's Orb"` → «Сфера златокузнеца»). Цифры — со ссылкой на расчёт и дату («по расчёту POETH на ценах 30.10.2026»).
- **О новой лиге — ничего до патчноутов.** Раздел-каркас `pending` и ссылка на патчноуты GGG.
- Новичку — коротко и по делу, первым словом пункта — действие (`**Пройдите…**`). Детали для опытных — `expert`.
- Переходы в POETH — блоком `app`, а не словами «откройте вкладку».
