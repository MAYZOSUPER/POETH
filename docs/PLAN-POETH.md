# POETH (POE Trade Helper) — план

## Контекст
Компьютер с исходниками сломался, но приватный репо `MAYZOSUPER/POE-2-ACT-Compas` цел (30 коммитов, последний
29.06.2026): Electron 33 + TS + React 18 + electron-vite + zustand, прозрачный оверлей, хоткеи (переназначаемые),
трей, чтение `Client.txt`, RU/EN, прайс-чек PoE2 (trade2 по POESESSID), handoff-доки (`MEMORY.md`, `PLAN.md`,
`docs/plan-companion.md`). Берём его за основу.

Цель — одно приложение **POE Trade Helper (POETH)** с переключателем **PoE 1 / PoE 2**. Сначала PoE 1: релиз
**v0.1.0 к 11.11.2026** (лига 3.30, по сторонним данным, стартует 13.11 PST — будет запас), затем PoE 2
(компас по актам уже есть + трейд).

**Главный принцип:** супер удобное и полезное приложение, одинаково хорошо работающее для **русского и английского**
клиента игры. Каждая функция проверяется на RU- и EN-фикстурах (текст предмета, whisper'ы, regex); интерфейс RU/EN.

**Аудитория — в первую очередь новички.** Люди бросают игру, потому что не получается фармить, не знают что/как
фармить, билд не дособирается. POETH должен помогать им честно зарабатывать: понятные подсказки «почему это выгодно»,
простой режим по умолчанию, объяснения терминов (RU/EN), безопасные советы. **Никаких авто-покупок и ботов** — только
подсказки, решения и клики делает игрок (это же и правила GGG).

**Монетизация:** приложение **бесплатное**, без платных функций; поддержка проекта — **Boosty**
`https://boosty.to/twistedthreadstudios`. Кнопка «Поддержать проект» в окне «О программе», настройках, меню трея,
в конце мастера первого запуска (ненавязчиво); ссылка в README. `boosty.to` — в allowlist `openExternal`.

### Решения пользователя
- Новый приватный репо **POETH** с полной историей компаса; компас = PoE2-модуль; старый репо — архив.
- Клиент игры **RU и EN** с первого релиза.
- К 11.11 обязательно: **прайс-чек с модами** (как APT), **трейд-окно в игре + избранное**, **live search +
  уведомления**, **regex-строки** (карты, торговец, свои сохранённые строки), **менеджер входящих сделок**.
- Прайс-чек — **Ctrl+D** (переназначаемый). Наводишь курсор на предмет → Ctrl+D → приложение само шлёт в игру
  Ctrl+C (с 3.29 сразу расширенный формат с тирами), читает буфер, **восстанавливает** старый буфер, показывает окно цены.
- Вход в аккаунт — можно, но **максимально безопасно** (см. раздел ниже).
- После релиза: учёт богатства (как Exilence/Wealthy Exile), **помощник по флиппингу** валюты и предметов, PoE 2 трейд.

## Принцип «всё в одном»
POETH — одна программа вместо десятка сайтов и утилит: всё нужное для трейда и прогресса в PoE1 доступно поверх игры,
без переключения в браузер. Каждую новую функцию оцениваем вопросом «какой сайт/инструмент она заменяет и экономит ли
игроку переключение». Сейчас приоритет — качественный PoE1; PoE2 — после (времени хватает).

### Вход в аккаунт и безопасность («чтобы не могли утащить аккаунт»)
Без входа работают прайс-чек, bulk-обмен, regex, менеджер сделок. Вход нужен для live search.
**Direct whisper / телепорт через запросы сайта НЕ делаем** — GGG через мейнтейнеров PoB (14.12.2025, PR PoB-PoE2 #1306)
предупредила о риске бана. Разрешено: «Скопировать whisper», «Вставить whisper в чат без отправки» и «Открыть лот в
трейд-окне», где игрок сам жмёт кнопку сайта.
**То же для «Travel to Hideout» (ТП в хайдаут продавца):** это не команда чата, а веб-запрос сайта к серверу GGG с
cookie сессии — приложение его **не отправляет**. Только официальный сайт в трейд-окне, кнопку жмёт игрок. Никаких
программных кликов и `executeJavaScript` по кнопкам сайта в `siteView`. Удобство — за счёт того, что «Открыть лот»
сразу показывает нужный лот в трейд-окне (1–2 клика игрока).
- **Пароль приложение не видит:** вход только на официальной `pathofexile.com/login` в `siteView`; пароль/2FA пользователь
  вводит сам на сайте GGG. Ни логин, ни пароль не храним.
- **Изолированная сессия** `session.fromPartition('persist:poe-account')` — её используют только `siteView` и сетевой слой
  (`net.request({session, useSessionCookies:true})`, `ws` с cookie из неё). Наши окна (оверлей, компаньон, сайдбар) на
  другой сессии. Cookies на диске шифруются fuse **`EnableCookieEncryption`** (DPAPI) через `@electron/fuses` при сборке.
- **POESESSID никогда не попадает в renderer:** IPC `auth.status()/login()/logout()` + событие смены статуса; чтение cookies — только main.
- **Allowlist хостов:** сессия аккаунта — только `*.pathofexile.com` (+ `challenges.cloudflare.com` для проверки CF).
  poe.ninja/poeprices/GitHub — отдельная сессия без cookies.
- **siteView:** `sandbox:true`, `contextIsolation`, без `nodeIntegration`/preload; навигация только внутри pathofexile.com,
  остальное → системный браузер; `window.open`/загрузки/разрешения запрещены; `webviewTag` выключен.
- **Hardening:** fuses `RunAsNode=off`, `EnableNodeCliInspectArguments=off`, `OnlyLoadAppFromAsar=on`,
  `EmbeddedAsarIntegrityValidation=on`; CSP в наших окнах; проверка `event.senderFrame` во всех IPC; `openExternal` — https+allowlist.
- **Выход** чистит partition. Фолбэк «вставить POESESSID» → `cookies.set` в partition + копия в `safeStorage` (уже есть
  `secretStore.ts`), предупреждение «никому не передавайте». Без телеметрии и своих серверов; логи маскируют cookie.
- UA: `app.userAgentFallback` = Chromium UA + ` POETH/<ver>` (один на окно и API — `cf_clearance` привязан к UA);
  `disable-blink-features=AutomationControlled`; удаляем атрибут `Partitioned` у cookies pathofexile.com (как APT).
  На Cloudflare-челлендж (HTML 403 / «Just a moment») UI предлагает «Открыть трейд-окно» и пройти проверку там.

### Сеть и лимиты (`src/main/net/`)
- `rateLimit.ts` (чистый, тестируемый): лимитер на политику (search / fetch / exchange / live-fetch) с несколькими окнами,
  стартовые значения — проверенные лимиты (search `5:10:60,15:60:300,30:300:1800,600:21600:3600`, fetch
  `12:4:10,16:12:300,50:300:300,1000:21600:1800`, exchange `5:15:60,10:90:300,30:300:1800`), ресинк по `x-rate-limit-*`,
  `retry-after` → `blockedUntil`.
- `tradeGateway.request({kind, priority:'interactive'|'background'})`: интерактивные (Ctrl+D) вперёд; **fail-fast** — если
  ждать >1.5 с, сразу ошибка с обратным отсчётом и кнопкой «повторить», без вечного спиннера; фоновые (live) — только если
  остаётся ≥25% окна. Кэш 5 мин по хэшу запроса (повторный Ctrl+D бесплатен). Лиги — авто-выбор новой лиги, обновление раз в час.

### Данные и два языка клиента
- `tools/data/sync-apt-data.mjs`: скачивает данные APT по пину (en, ru) → `resources/data/poe1/{en,ru}/`, строит `*.index.bin`,
  пишет `data.meta.json {aptSha,date,sha256}`. Протокол `poe2img://` → `poeth://`, `poeth://data/<game>/<lang>/<file>`
  (сначала `userData/data` для обновлений без переустановки, потом bundled).
- Язык предмета определяется по первой строке (`Item Class:` / `Класс предмета:`) → нужный набор данных. В запросы всегда
  идут **английские** `refName` и trade stat id → русские предметы ищутся корректно.

## Функции первого релиза (детали)
1. **Прайс-чек (оверлей):** строки модов (галочка, min/max, тир, % ролла; по умолчанию ±10%), псевдо-статы (сумма резистов,
   жизни…), фильтры предмета (ilvl, линки, сокеты, influence, corrupted), пресеты; уники/камни/карты/кластеры/флаконы;
   валюта, карточки и прочий bulk → `/api/trade/exchange`. Результаты: цена, кол-во, возраст, аккаунт, онлайн; у мерчант-
   листингов — комиссия в золоте и «купить в трейд-окне», у in-person — whisper. Кнопки: «Открыть в трейд-окне»,
   «В избранное», «Live search по этому запросу».
2. **Трейд-окно + избранное:** папки, сохранить текущий поиск из `siteView`, переименовать/перенести/архив, импорт/экспорт
   Better Trading `3:`; лига «текущая» по умолчанию. `FavSearch{id,folderId,title,game,type,slug,league?,notes?,live?{enabled,notify}}`.
3. **Live search:** до 10 (настройка до 20) поисков; подключения через 2.5 с, реконнект 3 с + jitter, 429 → бэкофф 30 с…10 мин,
   401 → ждём входа, 404 → поиск недействителен; `{"new":[ids]}` → батч 300 мс → fetch → разбор `item.extended.text` →
   тост + звук в оверлее, Windows-уведомление, если игра не в фокусе. Хоткей «whisper последней находки» **вставляет текст в
   чат, но не отправляет**. Транспорт за интерфейсом; фолбэк — скрытое окно на сайте, если Cloudflare не пустит `ws`.
4. **Regex:** генератор данных из RePoE (EN+RU): моды карт (domain `area`) → кратчайшая уникальная подстрока, проверка на
   ложные срабатывания против всех модов + строк подсказки карты (`extra-lines`); движок: жадное покрытие подстроками,
   `"!a|b"` для нежелательных, `"a|b"` для «любой из», отдельные термы для «обязательно», пороги `atLeast(n)`
   (≥80 → `([89].|\d..)`), лимит **250** символов со счётчиком; `emulator.ts` повторяет поиск игры и проверяет строку.
   Страницы: **Карты** (моды хочу/не хочу, количество/стая/редкость/доп. карты/скарабеи/валюта, осквернённые/неопознанные),
   **Торговец** (линки, цвета сокетов, скорость передвижения, уровни камней), **Библиотека** своих строк с хоткеями вставки
   1–5 (Ctrl+F → вставить).
5. **Менеджер сделок:** парсинг whisper'ов из `Client.txt` (EN `@From`/`@To`, RU `@От кого`/`@Кому`, обычные и bulk —
   regex'ы APT), карточки входящих/исходящих поверх игры: invite / trade / kick / «спасибо» / «продано» / «ещё актуально?» /
   whois / hideout (одна команда в чат на клик — правило GGG), звук, история, игнор проданного, предупреждение по
   чёрному списку PoE Hub (`blacklist.csv`, MIT). **Подсветка ячейки стэша** по `left/top`: сетка 12×12 / quad 24×24,
   позиция по высоте окна игры + ручная калибровка.

## Помощник по флиппингу (v0.2, после релиза; можно начать параллельно — файлы независимы)
**Источник данных:** с 3.29 GGG открыла почасовой фид обмена валюты **без авторизации**:
`GET https://web.poecdn.com/api/currency-exchange[/<realm>][/<hourId>]` → `{next_change_id, markets:[{league, market_id, market_pair:[A,B],
volume_traded:{A,B}, lowest_stock, highest_stock, lowest_ratio, highest_ratio}]}` (id = metadata-пути, напр. `CurrencyRerollRare`=chaos;
~66 КБ gzip/час, прошлые часы кэшируются навсегда, текущий час недоступен). Живого стакана публично нет (только в игре, Alt над Market Ratio).
Bulk `/api/trade/exchange` для валюты почти пуст (вся валюта у Фаустуса) — нужен только для того, чего нет на обмене (карты и т.п.).

**Валютная доска (MVP):**
- Загрузка последних 24 ч при старте, дальше раз в час (+jitter); маппинг metadata-id → имя/иконка/trade-tag (RePoE `base_items`
  + `/api/trade/data/static`), RU/EN имена из данных APT.
- Статистика пары за 1/6/24 ч: `vwap`, `lo/hi` (взвешенная медиана нормализованных min/max — **нормализовать направление пары**),
  `spread=(hi−lo)/vwap`, ликвидность (chaos-экв./час), активные часы, волатильность, глубина.
- Маршруты C→X→C, D→X→D, C→X→D, D→X→C; прибыль на единицу минус **комиссия в золоте** (за каждую купленную единицу:
  chaos 15, exalted 20, divine 250… — таблица как обновляемые данные, poedb), метрика «прибыль на 1000 золота»
  (продавать в divine дешевле по золоту, чем в chaos).
- Фильтры: ликвидность ≥2 div/ч, активность ≥18/24, спред 3–25%, волатильность ≤0.25, глубина ≥5× ордера, отсекать тренд.
  Оценка уверенности 0–1, размер ордера с «делящимися» целыми соотношениями, лимит 10 ордеров (=5 флипов).
- Строка UI: «купи X по ≤a, продай по ≥b, ~P chaos/ч (оценка), уверенность ●●○». Плюс трекер **divine:chaos** (24ч/7д, алерт
  при выходе из коридора). Дисклеймеры: «оценка по последнему часу, не live, не финансовый совет, проверь в игре (Alt над Market Ratio)».
**Предметы (MVP):**
- Тиры уников T0/T1/T2 считаем сами из poe.ninja (`divineValue`, с учётом `count`/`listingCount`, вариантов, линков, Foulborn),
  в строках poe.ninja есть готовые `tradeInfo` (stat-фильтры) → сразу запрос на трейд.
- «Недооценённые уники»: выбранные уники + медиана poe.ninja → поиск с `price.max = k·медиана`, `status:securable`
  → в live search (через наш безопасный вход) и кнопка «проверить сейчас» (≤10 предметов за клик, в рамках лимитов).
- Варианты/линки: список «6L vs без линков» по poe.ninja (`P6L − Pbase − стоимость 6-линка`).
- Антискам: `pricefixers.csv`/`blacklist.csv` PoE Hub, игнор одиночных выбросов (<0.5× медианы следующих 5), ≥3 листинга в ±15%,
  не старше недели, проверка варианта/порчи/имплицитов.
- poe.ninja просит десктоп-приложения ходить через свой бэкенд → для v0.2 маленький прокси (Cloudflare Worker, кэш 15 мин, ETag).
**Позже:** OCR панели Market Ratio по хоткею, оценщики кластеров (курируемые списки нотаблей), история/тренды, PoE2
(тот же фид `realm=poe2`, базовая валюта Exalted).
**Нельзя/не делаем:** авто-покупки и авто-whisper, постоянный опрос поиска трейда (бот-подобно), «живой» стакан.

## Timeless-джуэлы
Отдельного сайта «цена по сиду» нет — все делают «калькулятор → поиск на трейде». Цена = сид + (иногда) завоеватель/keystone +
лучшее гнездо на дереве. **Завоеватель меняет только keystone**, ноды у всех завоевателей одного джуэла при одном сиде одинаковы.
Trade: 28 stat id `explicit.pseudo_timeless_jewel_<завоеватель>` (23 обычных вкл. legacy + 5 Abyss 3.29), значение = сид,
поиск группой `{"type":"count","value":{"min":1},"filters":[{id, value:{min:seed,max:seed}}, …]}`.
- **v0.1 (входит в S4, прайс-чек):** распознаём джуэл по stat-ref (RU-склонения «…воинами Каома» — только через данные, не regex
  по EN); поиск по точному сиду, чип «любой завоеватель» по умолчанию (для Glorious Vanity / Militant Faith / Elegant Hubris —
  «точный», там keystone влияет на цену) + опциональные моды преданности Militant Faith; **добавить 5 legacy-завоевателей**
  (Zerphi, Kiloava, Deshret, Venarius, Chitus — их нет в данных APT), убирать диапазоны расширенной копии `5972(2000-10000)`;
  при пустом результате — «нет точных листингов» (а не «ничего не стоит»). Кнопки: «Открыть в калькуляторе Vilsol»
  `https://vilsol.github.io/timeless-jewels/tree?jewel=<1..6>&conqueror=<Имя|Any>&seed=<n>&mode=seed` (Abyss-джуэлы → подсказка про PoB),
  «Открыть на трейде». Стоимость: 1 search + 1 fetch.
- **v0.2+ «умная оценка»:** свой clean-room калькулятор на TS в worker'е (TinyMT32 по `[node id, seed]`, `AlternatePassiveSkills/
  Additions/TreeVersions` — по описанию алгоритма; код Vilsol GPL — **не копируем**; лукап-таблицы PoB/Regisle — MIT, можно
  для лёгких джуэлов), исход сида по 21 гнезду, оценка лучшего гнезда по правилам на джуэл, обратный поиск «сиды с таким же
  или лучшим исходом» → один count-запрос до 180 сидов → реальные аналоги по цене. Нижняя граница — цена poe.ninja по имени
  (через прокси v0.2). После 3.30 перепроверить данные дерева.
