# Трекер карт и сессия фарма (S11b)

Часть учёта богатства: забеги по `Client.txt` PoE1 через общий тейлер `services/gameLog.ts` (его же читают
команды чата и менеджер сделок; файл, выбранный во вкладке «Сделки», — свой путь лога и для трекера).
Только чтение лога: никаких действий в игре. Стэш, цены и прибыль за карту — S11a.

## Забег
- Вход в зону — `Generating level N area "<id>" with seed S` (служебная строка, одинакова в EN и RU клиенте).
  **Экземпляр зоны = areaId + seed**: при повторном входе в ту же карту (порталы туда-обратно, перезаход после
  смерти) seed тот же, у новой карты того же типа — другой. Сверено по настоящему Client.txt.
- Забег начинается входом в карту (или прочий контент) из хайдаута/города и заканчивается входом в **другой**
  экземпляр (события `runEnd(A)` → `runStart(B)` подряд; `endTs` = последний выход из A) или «Стоп» сессии.
- Зона, в которую вошли прямо из зоны забега (побочная область, комнаты лабиринта), — часть того же забега;
  возврат из неё в карту — не новый вход.
- `activeMs` — время внутри зон забега без пауз сессии; `entries` — входов (первый + порталы/перезаходы);
  `deaths` — `has been slain` / `был повержен` в зонах забега (в группе — все в зоне: имени своего персонажа
  в логе нет); ярус = уровень области − 67 (68…84 → 1…17).
- Имя зоны на языке клиента — `[SCENE] Set Source [<имя>]` или «You have entered …» / «Вы вошли в область …».

| Вид зоны | Как узнаём (`shared/farm/zones.ts`) |
|---|---|
| хайдаут | `Hideout*` |
| город/хаб | `*_town`, `HeistHub`, `Labyrinth_Airlock`, `DeepwaterHub`, прочие зоны уровня 1 (хабы лиг) |
| кампания | `N_…` (кроме `N_Labyrinth_*`) |
| карта | `Map*`, `*_MapGuardian*` (память) |
| прочий контент | остальное: ограбления, лабиринт, Мэйвен, Легион… |

Строки событий RU: «Вы вошли в область {0}.», «{0} был повержен.» — тексты игры из BackendErrors (выгрузка
данных клиента `LocalIdentity/poe2-data`: `data/backenderrors.json`, `data/russian/backenderrors.json`; кода
оттуда нет). EN сверено по настоящему Client.txt. В `CLIENT_STRINGS` APT событий области нет — только
`CHAT_SYSTEM` (`^: (?<body>.+)$`).

## Сессия
«Начать / Пауза / Продолжить / Стоп» (`farm:*`). Без сессии забеги тоже пишутся (`sessionId: null`).
- Пауза снимается сама при входе в зону забега (игрок вернулся к игре).
- «Начать» посреди карты — текущий забег идёт в сессию. «Стоп» закрывает открытый забег.
- Статистика: время без пауз, карт, карт в час (с минуты), среднее время завершённой карты, смерти,
  прибыль и доход в час (если S11a сообщил прибыль забегов).
- Выход из приложения — сессия на паузу (неизвестно, что игрок делает без приложения); сбой — то же с момента
  последней записи (раз в минуту, пока время идёт). При запуске строки хвоста лога после выхода (не старше 2 ч)
  проходят как обычные; если входа не было и игрок всё ещё в зоне открытого забега — он снова «внутри».

## Контракт с S11a (main, в процессе — `src/main/services/farmSession.ts`)
```ts
onFarmEvent(cb: (e: FarmEvent) => void): () => void   // подписка в любой момент, даже до подъёма домена
getFarmState(runsLimit?): FarmState                    // текущий забег, сессия, статистика, история
setRunProfit(runId, { chaos } | null): Promise<boolean> // прибыль забега в хаосах-эквиваленте (может быть < 0)
```
`FarmEvent`: `runStart` / `runEnd` (`run: FarmRun`, `at`) и `session` (`start|stop|pause|resume`). На переходе
карта A → карта B — синхронно `runEnd(A)`, затем `runStart(B)`: один снапшот стэша годится как «после A» и
«до B» (лут A игрок сложил в хайдауте до входа в B). Типы — `src/shared/types/farm.ts`.
Прибыль хранится в забеге (`farm.json`) и даёт «доход в час» сессии в панели и виджете.

## UI
- `<FarmPanel />` (`renderer/src/panels/farm/FarmPanel.tsx`) — самодостаточная панель для вкладки «Богатство»
  (S11a): кнопки сессии, статистика, текущая карта, история забегов и прошлых сессий, включение виджета.
- Виджет поверх игры (`overlay/farm/widget.tsx`, слой toasts, выше уведомлений): таймер карты, карт за сессию,
  карт в час, доход в час. По умолчанию выключен (`farm.json` `config.overlayWidget`), мышь проходит в игру.
