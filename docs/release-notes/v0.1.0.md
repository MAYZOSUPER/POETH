# POETH v0.1.0

**POE Trade Helper (POETH)** — бесплатный помощник для Path of Exile поверх игры. Наведите курсор на предмет,
нажмите `Ctrl+D` — и увидите честную цену. Трейд, обмен валюты, учёт богатства и гид прокачки собраны в одном
приложении. Работает с русским и английским клиентом игры. Это первый выпуск для PoE 1; для PoE 2 есть трекер
кампании и цена предмета.

## Главное

- **Цена предмета по `Ctrl+D`** прямо у курсора и подсказка, что делать с вещью: продать торговцу, копить
  на продажу пачкой или выставить за ~X. Заметку цены можно скопировать одной кнопкой.
- **Редкие предметы ищутся точно:** по той же базе, ценные свойства уже отмечены. «Цена на рынке» — самые
  дешёвые похожие лоты без приманок.
- **Валюта — по курсу обмена у Фаустуса** (почасовые данные GGG), а не по устаревшим объявлениям на сайте.
- **Трейд-окно в игре** (`Ctrl+Shift+T`) с папками избранного и импортом из Better Trading, **live search**
  с уведомлениями поверх игры.
- **Сделки:** карточки входящих и исходящих сделок, подсветка ячейки тайника, чёрный список PoE Hub.
  **Команды чата по клавишам:** `F5` — в убежище.
- **«Обмен»:** что выгодно купить и продать у Фаустуса, по реальной цене покупки и продажи с комиссией
  в золоте. Таблицу «Рыночный курс» можно считать с экрана по `Alt+D` (бета).
- **«Богатство»:** стоимость тайника и что прибавилось; **трекер карт** — время, смерти и доход в час.
- **Regex-строки** для тайника и торговца: моды карт, свойства предметов, своя библиотека на клавишах.
- **Гид прокачки PoE 1** поверх игры (`Ctrl+Shift+G`): шаг меняется сам при входе в новую зону.
- **Русский и английский клиент:** названия предметов и валют — на языке игры, пояснения — на языке
  интерфейса. Простой режим для новичков и экспертный.

## Как установить

1. Скачайте `POETH-Setup-0.1.0.exe` ниже и запустите. POETH встанет в вашу папку пользователя, права
   администратора не нужны.
2. Windows покажет «Система Windows защитила ваш компьютер» — нажмите **«Подробнее»**, затем **«Выполнить
   в любом случае»**. Так Windows встречает программы без платной цифровой подписи.
3. Мастер первого запуска поможет выбрать язык, игру и сайт трейда. В игре включите режим **«Окно без рамки»**
   или **«Окно»**.

Без установки — `POETH-Portable-0.1.0.exe`: запускается сразу, новые версии скачиваются вручную.

Что-то не работает — [частые вопросы](https://github.com/MAYZOSUPER/POETH/blob/main/docs/FAQ.md).

## Известные ограничения

- **Лига 3.30 (старт 13.11).** На новую лигу POETH переключится сам. Новые свойства предметов он подтягивает
  с сайта трейда в течение суток. Полные данные 3.30 придут обновлением без переустановки, как только выйдут
  данные новой лиги: по опыту прошлых лиг — в первые 1–3 дня. До этого часть новых предметов может быть
  «не распознана». Когда появится тост «Данные обновлены», перезапустите POETH. Для этого в настройках должно
  быть включено «Проверять обновления» (включено по умолчанию).
- **Таблица «Рыночный курс» с экрана — бета.** Распознавание может ошибиться, особенно при другом разрешении
  или масштабе Windows. Сомнительные ячейки помечены «проверьте» и не идут в расчёт, пока вы их не подтвердите.
  Сверяйте цифры с игрой.
- **PoE 2:** пока только трекер кампании и цена предмета. Трейд-окно, live search, сделки, regex, «Обмен»,
  «Богатство» и гид прокачки — только для PoE 1.
- **Только Windows 10 и 11 (64 бита).** В эксклюзивном полноэкранном режиме игры окна POETH не видны.
- **Portable-версия** не обновляется сама и не показывает уведомления Windows: уведомления поверх игры
  работают как обычно.

POETH — неофициальный фанатский инструмент, не связан с Grinding Gear Games и не одобрен ими.
