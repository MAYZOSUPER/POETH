# Сайт POETH

Статичные страницы для GitHub Pages: https://mayzosuper.github.io/POETH/ (публикует `.github/workflows/pages.yml`).
Без сборки, без CDN и внешних скриптов. Стиль «Золото компаса», токены — в начале `styles.css`.

| Файл | Что |
|---|---|
| `index.html` | главная; каждый текст дважды: `<span lang="ru">` и `<span lang="en">` |
| `guide/index.html` | **гайд по всем функциям приложения** (RU/EN) — постоянный адрес, см. ниже |
| `guide/guide.css` | стили гайда: оглавление, схема окна, карточки функций (общее — из `styles.css`); их же берёт `bug/` |
| `bug/index.html` | «Сообщить об ошибке» (RU/EN, S56): аккаунт GitHub, что приложить, скриншот, приватность, кнопка на форму `.github/ISSUE_TEMPLATE/bug.yml` |
| `styles.css` | токены и стили; CSS прячет текст невыбранного языка |
| `app.js` | кнопки RU/EN, заголовок и описание страницы под язык (у гайда — свои, `data-ru`/`data-en` у `<title>` и description) |
| `assets/fonts/` | Cormorant SC Bold и Golos Text, урезаны до латиницы и кириллицы (woff2), лицензии OFL рядом |
| `assets/img/` | кадры интерфейса `price-*`, `trade-*`, `deals-*` (RU и EN, WebP), `regex-*` (PNG, для гайда), `guide/*` (снимки dev-стендов S39–S47 с тестовыми данными, PNG — **не снимки из игры**) и `og.png` 1200×630 для превью ссылки |
| `assets/brand/` | знак, надпись POETH, иконки вкладки |
| `strategies/` | каталог стратегий советника (скрыт вместе с советником, в меню не ссылается) |
| `starters/` | **«Стартеры» лиги (ST3)** — каталог стартеров, только просмотр, см. ниже |

## «Стартеры»: `starters/`

Каталог стартеров лиги — тот же список, что во вкладке «Билд» приложения. Играть по стартеру — только в приложении,
кнопка страницы ведёт на `guide/#starters`. Строгая CSP (только свои файлы), всё из данных — через `textContent`.

| Файл | Что |
|---|---|
| `index.html`, `starters.css`, `starters.js`, `lang.js` | страница (RU/EN), стили с префиксом `sr-`, отрисовка, язык до первой отрисовки |
| `starters-core.js` | **сгенерирован**: бандл `src/shared/starters/site.ts` — тот же валидатор, загрузка списка (до анонса — прошлая лига), знаки, фильтры и сортировки |
| `data/index.json`, `data/<лига>.json` | **сгенерированы**: копии `resources/data/poe1/starters` |
| `names.json` | **сгенерирован**: классы и восхождения RU (данные дерева), навыки стартеров RU/EN (данные камней) |

Сгенерированные файлы собирает `node tools/starters/build-site.mjs` (`--check` — только проверить; это же проверяет
`npm test`, `tests/starters/site.test.ts`). `tools/starters/add-starter.mjs` после записи стартера пересобирает их сам —
после коммита в `main` сайт выкладывается вместе со списком. Пока список текущей лиги пуст, страница пишет
«Стартеры 3.30 появятся после анонса лиги» (и показывает прошлую лигу, если она есть в индексе).

## Язык
По умолчанию — язык браузера: `ru`, `be`, `kk` → RU, остальные → EN. Выбор кнопкой запоминается в браузере
(общий для главной и гайда). Ссылка на нужный язык: `?lang=ru` или `?lang=en`.

## Как заменить картинки на скриншоты из игры
Сохранить под теми же именами (`price-ru.webp`, `price-en.webp` …), ширина в 2 раза больше показа
(прайс-чек ≥ 1080 px, трейд-окно и сделки ≥ 1600 px), и поправить `width`/`height` у `<img>` в `index.html`
и `guide/index.html`, чтобы страница не прыгала при загрузке. Тексты «Картинки … — макеты» на главной
(«Как это выглядит») и в шапке гайда убрать.

## Включить публикацию
Один раз: Settings → Pages → Source: «GitHub Actions». Дальше каждый push в `main` с изменениями в `site/` выкладывает сайт.
