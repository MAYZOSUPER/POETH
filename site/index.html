Узнайте цену предмета, не выходя из игрыPrice any item without leaving the game

POETH — бесплатный оверлей для трейда в Path of Exile 1 и 2. Наведите курсор на предмет, нажмите Ctrl+D, и цена появится прямо поверх игры. POETH is a free trade overlay for Path of Exile 1 and 2. Hover an item, press Ctrl+D, and its price appears right over the game.

Там же — трейд-окно, обмен валюты, учёт богатства и гид прокачки. Работает с русским и английским клиентом. Простой режим и подсказки для новичков, без ботов и авто-покупок. Also inside: a trade window, currency exchange, wealth tracking and a leveling guide. Works with Russian and English game clients. A simple mode and hints for beginners, no bots and no auto-buying.

Установка за три шагаInstall in three steps

  1. Скачайте установщикDownload the installer

    Файл POETH-Setup-версия.exe лежит на странице релизов GitHub. The POETH-Setup-version.exe file is on the GitHub releases page.

    Открыть релизыOpen releases

  2. Запустите егоRun it

    Нажмите «Далее»: POETH встанет в вашу папку пользователя, права администратора не нужны. Если Windows показал синее окно «Система Windows защитила ваш компьютер», нажмите «Подробнее», затем «Выполнить в любом случае». Click Next: POETH installs into your user folder, no administrator rights needed. If Windows shows a blue “Windows protected your PC” window, click More info, then Run anyway.

    Так Windows встречает программы без платной цифровой подписи. Код POETH открыт, а установщик собирается на GitHub из этого кода. This is how Windows treats programs without a paid code-signing certificate. POETH is open source, and the installer is built on GitHub from that code.

  3. Откройте игру и POETHOpen the game and POETH

    Оставьте галочку «Запустить POETH»: мастер первого запуска поможет выбрать язык и игру. В игре включите режим «Окно» или «Окно без рамки», наведите курсор на предмет и нажмите Ctrl+D. Keep “Run POETH” checked: the first-run setup helps you pick the language and the game. In the game, switch to Windowed or Borderless windowed mode, hover an item and press Ctrl+D.

  4. Без установки — POETH-Portable-версия.exe на той же странице: запускается сразу, новые версии скачиваются вручную. No install: POETH-Portable-version.exe on the same page starts right away; you download new versions yourself.

Почему это безопасноWhy it is safe

Открытый кодOpen source

Весь код лежит на GitHub под лицензией MIT. Установщик собирается из него автоматически, и проверить его может любой. All code is on GitHub under the MIT license. The installer is built from it automatically, and anyone can check it.

Вход только на сайте GGGSign-in only on the GGG site

Вход нужен только для live-поиска и учёта богатства. Вы входите на официальной странице pathofexile.com, пароль видит только сайт GGG. Прайс-чек, regex, сделки и обмен валюты работают без входа. You only need to sign in for live search and wealth tracking. You sign in on the official pathofexile.com page, and only the GGG site sees your password. Price check, regex, deals and currency exchange work without signing in.

Данные остаются у васYour data stays with you

Нет телеметрии, рекламы и своих серверов. POETH обращается только к сайту трейда pathofexile.com и открытым данным GGG, к сервису цен poe.watch для учёта богатства и к GitHub за обновлениями. No telemetry, no ads and no servers of our own. POETH only talks to the pathofexile.com trade site and GGG's public data, the poe.watch price service for wealth tracking, and GitHub for updates.

Без ботов и авто-покупокNo bots, no auto-buying

Одно ваше нажатие — одно действие программы, как требуют правила GGG для сторонних программ. Сообщение продавцу POETH вставляет в чат игры, а Enter по умолчанию нажимаете вы. One press from you is one action from the app, as GGG's rules for third-party tools require. POETH pastes a message to the seller into game chat, and by default you press Enter.

Официальные сборки — только на странице релизов репозитория MAYZOSUPER/POETH. Файлы с других сайтов не запускайте. Official builds are only on the releases page of the MAYZOSUPER/POETH repository. Do not run copies from other sites.

Частые вопросыQuestions

Здесь — самое частое. Остальное, в том числе как переназначить клавиши и как удалить POETH, — в полном списке вопросов. The most common ones are here. The rest, including how to change hotkeys and how to remove POETH, is in the full FAQ.

Оверлей не появляется поверх игрыThe overlay does not show over the game

Включите в настройках графики игры режим «Окно» или «Окно без рамки». В полноэкранном режиме Windows не даёт другим программам рисовать поверх игры.

In the game's graphics settings, choose Windowed or Borderless windowed mode. In exclusive fullscreen, Windows does not let other programs draw over the game.

Ctrl+D ничего не делаетCtrl+D does nothing

Скорее всего, игра запущена от имени администратора. Windows не даёт обычной программе управлять таким окном. Запустите игру обычным способом или POETH тоже от администратора: правый клик по ярлыку → «Запуск от имени администратора». POETH сам предупредит, если заметит это.

Most likely the game is running as administrator. Windows does not let a normal program control such a window. Start the game normally, or start POETH as administrator too: right-click the shortcut → Run as administrator. POETH warns you when it detects this.

Ещё одна частая причина — Ctrl+D занят другой программой, например Awakened PoE Trade. POETH предупредит и предложит сменить клавишу.

Another common cause is that Ctrl+D is taken by another program, such as Awakened PoE Trade. POETH warns you and offers to change the key.

У меня русский клиент игры. Всё будет работать?Does it work with the Russian game client?

Да. POETH понимает предметы и в русском, и в английском клиенте, а названия предметов и валют показывает на языке игры. Язык самого POETH выбирается отдельно в настройках.

Yes. POETH reads items from both the Russian and the English client and shows item and currency names in the game's language. POETH's own language is set separately in its settings.

Чем отличается работа с PoE 1 и PoE 2?What is the difference between PoE 1 and PoE 2?

Игра выбирается переключателем в шапке окна POETH. Для PoE 1 есть всё: трейд, обмен валюты, учёт богатства, regex и гид прокачки. Для PoE 2 сейчас прайс-чек и трекер кампании.

You pick the game with the switch in the POETH window header. PoE 1 gets everything: trading, currency exchange, wealth tracking, regex and the leveling guide. PoE 2 currently has price check and the campaign tracker.

Windows пишет, что защитил компьютер. Это вирус?Windows says it protected my PC. Is it a virus?

Нет. Так Windows реагирует на программы без платной цифровой подписи. Код POETH открыт, а установщик собирается на GitHub из этого кода. Что нажать, показано в разделе «Установка».

No. This is how Windows reacts to programs without a paid code-signing certificate. POETH is open source, and the installer is built on GitHub from that code. See Install for what to click.

Могут ли забанить за POETH?Can I get banned for using POETH?

Честно: гарантий дать нельзя, GGG не проверяет и не одобряет сторонние программы. POETH устроен по тем же правилам, что Awakened PoE Trade: одно ваше нажатие — одно действие в игре. Он не читает и не меняет память и файлы игры и ничего не нажимает и не покупает сам.

Honestly, nobody can guarantee it: GGG does not review or endorse third-party tools. POETH follows the same rules as Awakened PoE Trade: one key press from you is one action in the game. It does not read or change the game's memory or files, and never clicks or buys anything by itself.

Да, все функции и все версии доступны каждому. Подписка на Boosty только поддерживает разработку: девлоги, голосования и имя в «Благодарностях» в программе. Функций она не открывает.

Yes, every feature and every version is open to everyone. A Boosty subscription only supports development: devlogs, polls and your name in the app's credits. It does not unlock features.
